# Porvenir Agencia Digital 🚀
Web oficial corporativa de **Porvenir Agencia Digital**. Unimos Ingeniería de Software, Diseño Web e Inteligencia Artificial para escalar negocios. No usamos plantillas lentas: desarrollamos activos digitales rentables y a medida.

## 🛠️ Servicios Principales
* **🤖 Automatización & IA:** Implementación de chatbots inteligentes a medida y agentes de voz (WhatsApp/Web) para atención ininterrumpida 24/7 y gestión de leads.
* **💻 Diseño Web a medida y Conversión:** Sitios web ultrarrápidos, Mobile First y optimizados en SEO Técnico, diseñados estratégicamente para maximizar ventas.
* **♿ UX & Accesibilidad:** Auditorías bajo la estricta normativa WCAG 2.1, evaluaciones heurísticas y diseño inclusivo para cumplir la ley y democratizar la tecnología.
* **🎓 Formación & Talleres IA:** Capacitación in-company 100% práctica sobre Inteligencia Artificial aplicada a la productividad real, atención al cliente y ventas.

# Porvenir Agencia Digital 🚀
Web oficial corporativa de **Porvenir Agencia Digital**. Unimos Ingeniería de Software, Diseño Web e Inteligencia Artificial para escalar negocios. No usamos plantillas lentas: desarrollamos activos digitales rentables y a medida.

## 🛠️ Servicios Principales
* **💻 Diseño Web & UX:** Sitios web a medida, ultrarrápidos y Mobile First, optimizados para SEO y diseñados para convertir. Con diseño UX estratégico y auditorías de accesibilidad WCAG 2.1 incluidas.
* **🤖 IA & Automatización:** Chatbots inteligentes para WhatsApp y web, agentes telefónicos con IA que atienden llamadas 24/7, y flujos de automatización a medida para cualquier proceso de negocio. Solución para cumplir la Ley 10/2025 sin ampliar plantilla.
* **📱 Apps Móviles:** Aplicaciones iOS y Android, nativas e híbridas, con integración de IA, APIs y CRMs. Arquitectura sólida y mantenible desde el primer día.

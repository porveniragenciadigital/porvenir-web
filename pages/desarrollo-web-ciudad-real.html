Preguntas frecuentes

¿Cuál es la diferencia entre diseño web y desarrollo web?

El diseño web se centra en la experiencia de usuario: qué aspecto tiene, cómo se navega y cómo se estructura la información para que el visitante convierta. El desarrollo web es la implementación técnica: el código que hace que eso funcione en el navegador. En Porvenir hacemos los dos, sin separación artificial de roles.

¿Puedo editar mi web después sin saber código?

Depende del tipo de contenido. Para contenido que cambia con frecuencia (blog, catálogo de productos, eventos), podemos integrar un CMS headless sencillo. Para webs corporativas con contenido más estático, el mantenimiento de textos e imágenes es muy sencillo incluso con conocimientos básicos, y te formamos en el proceso de entrega.

¿Hacéis mantenimiento web después del lanzamiento?

Sí. Ofrecemos bolsas de horas de mantenimiento mensuales para actualizaciones de contenido, pequeñas mejoras funcionales, monitoreo de disponibilidad y revisión de SEO técnico. El coste depende del volumen de horas contratadas.
